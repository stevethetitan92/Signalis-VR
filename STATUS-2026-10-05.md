[Code-review source archive](SignalisVR-code-review-0.7.26.zip). This is current code for review, with embedded asset payload sources, game binaries, raw logs and third-party binaries omitted. Missing/unsupported dependencies show UNAVAILABLE; both default ON. VR flashlight placement remains separate.
