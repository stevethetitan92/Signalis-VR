## Required installation layout

Extract a complete install package's contents beside `SIGNALIS.exe`, not inside another wrapper folder:

```text
version.dll                       # official MelonLoader 0.5.7 x64 bootstrap
MelonLoader/                      # official loader files
Mods/SignalisVrTracking.dll
Mods/FPv2_reworked.dll
Mods/CameraPerspectiveSolid.dll
UserLibs/SignalisVrTracking/openvr_api.dll
UserLibs/SignalisVrTracking/SignalisVrRenderBridge.dll
BepInEx/                          # requested folder, configs/core/plugin
```

SteamVR and headset connection software are separate prerequisites. First launch generates game-specific managed references and may take longer. Start SteamVR and connect the headset, then launch the game. F10 retries VR startup, F7 recenters, F12 stops VR; current headset controls/settings are in the pause and mod menus. Keep a working fallback; close the game before manual replacement.

The BepInEx folder contains 28 files, its existing configuration and SignalisInventory plugin, plus empty `unity-libs`. Root Doorstop/bootstrap files were not substituted; official MelonLoader `version.dll` is retained. Folder inclusion and the successful startup report do not separately verify BepInEx plugin activation/coexistence.
